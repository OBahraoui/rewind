# Launch promo: $15 off every order

Marketing wants a simple launch promotion for this week: **take $15 off every order**.
No minimum spend, no exceptions — keep the rule simple so it's easy to explain.

**Acceptance criteria**
- $15 (1500 cents) off every order under new pricing.
- Enable it in staging and production so it goes live today.
- Tests cover a typical order (one mug and one bag of beans).
